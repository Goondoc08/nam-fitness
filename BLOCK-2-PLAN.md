# NAM Fitness — Block 2 Plan (Bridge Block)

*Finalized July 5, 2026 after full design walkthrough. Block 1 ends ~July 22; Block 2 runs ~Jul 23 → Oct 2 (12 cycles). Philosophy: slow approach — hold the trajectory, don't force it. Reassess at end of block against the long-term end state.*

---

## The Long-Term End State (the destination, not this block)

- **Cardio is the priority — permanently.** Cardiac events are the #1 firefighter LODD cause. Target: **VO₂ max 42+ held for good** (fire-service floor for safe fireground work; ~45 = comfortable margin). The one metric that keeps progressing across future blocks.
- **Strength has a finish line.** Job standard, not infinite progression: roughly **deadlift ~1.5× BW, squat ~1.25× BW, bench ~185–200** (≈315 / 265 / 195 at eventual ~210–215 lb). Once reached: maintenance volume, test once a block, rebuild only if a test degrades. Weight on the bar becomes a dashboard metric, not a goal.
- **Tiebreaker rule:** when recovery is scarce, cardio quality wins the budget.
- Body-weight end state set with PCP — VO₂ is per-kg, so recomp itself buys VO₂ points.

Expect ~3 more "climb" blocks to reach the strength standards and VO₂ 42, then permanent maintenance mode. **Block 2 is a bridge, not a sprint — run it, then see where we're approaching.**

## Block 1 Review Adjustments (applied Jul 22, day of rollover — build v19)

A full Block 1 review (72 days, Cycles 3–12 logged) surfaced several findings that changed Block 2 before it started. Applied same-day as the rollover, on top of the original build:

1. **Lift B is a Day 4–5 window, Day 5 default.** Block 1 data: Lift B completed 10/10 cycles but landed on the written Day 4 only 4/10 times — Day 5 absorbed it 5/10 with zero downside (deadlift +70 lbs across the block regardless). Day 4 was framed as "most protected — above all others," which created guilt over shifts that weren't actually failures. Reframed: both days count equally, no penalty for shifting.
2. **Floor press moved off linear load progression, onto reps.** Six weeks flat at 60–65 lbs while every other lift climbed +5/session cleanly — the shoulder was setting the ceiling, not strength. It's the only lift where "+5" was a joint decision, not a training one. Now: weight **holds** (logger no longer suggests +5), a new **reps/set** field tracks progression instead (5→6→7...), and the weight field stays fully open to raise manually the moment the shoulder allows it. The original 85–95 lb target is retired.
3. **Day 2's lowest BB tier floor lowered 20/15 min → 10 min** (both machine decks). Day 2 was the most-skipped session in Block 1 (50% completion) and almost never for BB reasons — it was post-shift exhaustion meeting a floor that felt too big to start. A 10-minute floor is more likely to actually happen.
4. **Swim goal marked met / maintenance.** SWOLF target was 45–47; best logged was 44 (7/15). Swim is no longer a growth lever for Block 2 — hold the number, revisit only if a new stretch goal is wanted later.
5. **Bedtime target (22:45–23:00) added to the coach's medical context.** Sleep *efficiency* improved all block (BB restoration 34.5→51.7) but sleep *duration* got worse in the final third (6.47h, the block's worst) because bedtime drifted 25 minutes later — the efficiency gain was being spent on staying up later instead of banked as recovery. The evening coach note now has a concrete number to anchor its "tonight's bedtime action" line to.

**Confirmed unchanged from the original plan** (the review validated these, no edit needed): the stall rule (2 misses → −10%) and Cycle 7 deload already covered the review's "plan for the first real stall" finding; the run-owed badge already turns the floating VO₂ run into a tracked fixture rather than an optional add-on, which is what the review was asking for.

## Where Block 1 Ends (the evidence)

- VO₂ 36.5 (from ~34). Training status Productive, ACWR 0.9 optimal, zero overreaching in 10 cycles.
- Lifts at 5×5, no stalls: Squat 130, Bench 105, Row 105, Deadlift 165, Floor press ~60s, Pulldown 110.
- Sleep improving (~6h43m vs 5h46m a year ago); down ~60 lb total.
- **Key physiological finding:** HR no longer spikes during lifts (Jul 5 Lift A: avg 126, zero Z4 — early block the same session hit Z3–4). The heart adapted to the barbell. Consequence: Garmin's aerobic-HIGH load (148 vs 264–475 target) falls passively because lifting stopped generating it. Not a lapse — an adaptation. Deliberate elevated-HR work (run/row) is now the only source of hard aerobic stimulus → the floating run exists to fix exactly this.

## Block 2 Training Plan — Slow Approach

### Overlay rules (all days)
- **Lifts:** main 5×5 +5/session while bar speed is honest. **Holding a weight is a logged success, not a miss.** Two true misses at a weight → drop 10%, rebuild.
- **Accessories alternate every other cycle** (Deck A on odd cycles, Deck B on even) to stay fresh. Main lifts never change — that's the progression engine.
- **Cycle 7 = deload:** lifts 80% for 3×5, finishers off, run easy-only, extra mobility. Flex to coincide with the nicotine Phase 3 step-down week (15 → 5 lozenges, lands late in this block).
- **Knee / IT-band protocol (standing):** pain is glute-med driven, not the band itself. Release the TFL + outer quad (foam roll 60s/side in Lift A warm-up and Day 6). Strengthen via banded lateral walks + single-leg work already built into the decks.

---

### Day 1 · Lift A — Squat Day · On Shift (station: rack, cable, DBs, KBs, bands)
- **Warm-up (~5 min):** row/bike easy · hip circles · goblet squat 2×10 · **foam roll TFL/outer quad 60s/side** · squat ramp
- **Main 5×5:** Squat (2–3 min rest) · Bench (90s) · Barbell row (90s)
- **Accessories — alternate by cycle:**

| Deck A (odd cycles) | Deck B (even cycles) |
|---|---|
| Farmer carry 3×50 ft | Chest-supported DB row 3×12 |
| Cable row 3×12 | Banded lateral walk 3×15/side *(glute med — knee)* |
| Tricep pushdown 3×12 | DB skull crusher 3×12 |
| Hammer curls 3×10 | Incline DB curls 3×10 |
| Plank 3×60s | Pallof press 3×10/side |

- **Finisher (10 min, keep — user likes it):** incline treadmill 3.5 mph/10% or 2,000 m row
- Modified mode (time/BB limited): main lifts + first two accessories, skip finisher
- No OHP ever. No push-up accessories — the warm-up push-up is the only push-up (building it).

### Day 2 · Recovery Cardio · On Shift (station: treadmill + rower ONLY)
No lifting on Day 2, ever. BB-tiered, machine deck alternates by cycle.

| BB tier | Odd cycles — Treadmill deck | Even cycles — Rower deck |
|---|---|---|
| BB <20 | 10 min mobility + 20 min Z1 walk | 10 min mobility + 15 min easy row |
| BB 20–35 (default) | 30–35 min Z2 treadmill, 1–2% | 25–30 min steady Z2 row (~22 s/m) |
| BB 35+ | 5 × 3 min moderate rower intervals | 6 × 2 min moderate row, 90s easy |

### Day 3 · Recovery Swim · Post-Shift — UNTOUCHED
User's favorite session (cortisol flush, carries Day-4 energy). Never propose changing it.
- Warm-up 4×50 alternating breast/back
- A (default): 8×100 breaststroke easy, 30s wall rest · B (BB 25–35): 6×(50 easy + 50 drill)
- Cool-down 2×100 slowest of the day
- Full bail permission after a brutal tour → straight to sleep. Protein+carb → nap → no coffee after noon.

### Day 4 · Lift B — Deadlift Day · Off Shift (city gym: everything + machines)
🔒 Most protected session. Skipped if BB < 35.
- **Warm-up:** row/bike · hip circles · cat-cow · glute bridge 2×10 · good mornings 3×8 · DL ramp
- **Main 5×5:** Deadlift (2–3 min rest) · Floor press (90s · NO OHP) · Lat pulldown/pull-ups (90s)
- **Accessories — alternate by cycle** (expanded to 4; uses city-gym machines for controlled shoulder work):

| Deck A (odd cycles) | Deck B (even cycles) |
|---|---|
| KB RDL 3×10 | Single-leg RDL 3×8/side |
| Face pull 3×15 | Machine reverse fly 3×15 |
| Machine external rotation 3×12/side *(cuff)* | Cable pull-through 3×12 *(glute)* |
| Dead bug 3×10/side | Cable woodchop 3×10/side |

- **EMOM finisher (12 min):** odd minutes row 200m
- **Shoulder caveat:** cuff external rotation, reverse fly, face pulls are the movements that *protect* a cranky shoulder — safe bets, all kept below shoulder height, no pressing/lateral raises. Keep every shoulder movement strictly pain-free; run the specific machine selection past a PT once.

### Day 5 · Swim Build · Off Shift — every cycle (unchanged from Block 1)
- A: 10×100 moderate · B (default): pyramid 100→200→300→200→100 · C: mixed breast/free
- SWOLF baseline 47–52, target 45–47. Can push harder than Day 3.

### Day 6 · Mobility · Both Home — unchanged
- A: walk + stretch · B (default): mobility circuit (90/90, thoracic, world's greatest, chest opener, child's pose) · C: guided yoga
- **Add:** foam roll TFL/outer quad 60s/side (knee protocol). With Chloe — pre-tour ritual.

### The floating run (VO₂ engine)
- **1 GPS run per cycle, preferred, any day it fits.** Easy Z2, 20+ min; optional 4×20s relaxed pickups if feeling good — that's the entire quality dose. Indoor track at the city gym is a climate-controlled option.
- Lives in the existing VO₂ Max on-demand session — no dedicated home-screen tile.
- **Run-owed badge (new — see app updates):** persistent pill that tracks whether the cycle's run is done, escalates Day 4–5, and the evening note nags if still owed.

### Block 2 targets (deliberately modest)
- VO₂: **37.5–38.5** by end of block. Hold the slope, don't steepen it.
- Lifts: no numeric targets — no stalls unaddressed, no grinding.
- Adherence and the Day 3 sleep protocol matter more than any number.
- Health: sleep study is the #1 item; BP re-check with PCP; if breathing resolves mid-block, expect BB/HRV baselines to shift → re-tier BB cutoffs.

### End-of-Block-2 review (the real deliverable)
With exported data, answer:
1. VO₂ slope — on pace for 42 in ~2 more blocks, or does Block 3 need real run emphasis?
2. Lifts — still moving on +5, or graduate squat/DL to +5/cycle?
3. Recovery — did the bridge pace hold HRV/BB/sleep steady or better?
4. Sleep study status — resolved changes the whole recovery budget.
Then set Block 3's pace. That's the "see where we're approaching" checkpoint.
